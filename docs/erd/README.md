Обозначения:
* `PK` / `FK` / `UK` — первичный, внешний (внутри базы), уникальный ключ;
* комментарий `NULL` — колонка необязательна, всё остальное `NOT NULL`;
* `BK` — business key, отдаётся наружу; суррогатные `*_id` наружу не выходят;
* сущности с префиксом `EXT_` — таблицы **других** сервисов; пунктирная связь —
  логическая ссылка по BK, без `FOREIGN KEY` ([ADR-0001](../adr/0001-business-keys.md));
* на каждой таблице есть технические поля `created_at`, `updated_at` (триггер),
  `source_system`; в справочниках ещё `deleted_at` (soft delete). На диаграммах
  они показаны у основных сущностей, у остальных опущены для читаемости.
