# ADR-0009. `is_rx` выводится из `category`

**Статус:** принято · **Дата:** 2026-10-13

## Контекст
Контракт `v_sku` отдаёт и `category` (`rx|otc|supplement|device|cosmetics`),
и `is_rx`. Препарат может быть переведён из рецептурных в безрецептурные.

## Рассмотренные варианты
1. **Два независимых поля.** Позволяет, например, рецептурное медизделие.
   Отвергнут: допускает противоречие «категория `otc`, `is_rx = true`»;
   при переводе rx → otc легко поменять одно поле и забыть второе.
2. **Два поля + `CHECK (is_rx = (category = 'rx'))`.** Противоречие запрещено,
   но поле избыточно: каждое изменение требует менять оба.
3. **Хранить только `category`, `is_rx` выводить.** Выбран.

## Решение
В `sku` хранится только `category`. `v_sku.is_rx = (category = 'rx')`.
Перевод из рецептурных в безрецептурные — одно изменение `category`,
фиксируется в `sku_history` ([ADR-0006](0006-attribute-history.md)).

## Цена решения
* Рецептурность жёстко привязана к категории: рецептурное медизделие или БАД
  выразить нельзя — понадобится миграция с выделением поля.
