# ADR-0001. Формат business key

**Статус:** принято · **Дата:** 2026-10-13

## Контекст
DWH (ДЗ2) будет строиться на business keys: хабы Data Vault идентифицируют
сущность по BK. Ключ обязан быть стабильным при перезаливке источника,
человекочитаемым и не меняться никогда. Четыре сервиса — разные системы, ссылки
между ними возможны только логические, по BK.

## Рассмотренные варианты
1. **`serial` / identity как BK.** Отвергнут: при перезаливке источника номера
   переназначаются, и все ссылки из DWH «поедут». Прямо запрещено заданием.
2. **UUID.** Уникален глобально, генерируется без координации. Отвергнут:
   нечитаем для человека (аналитик не продиктует его по телефону, не найдёт
   глазами в логе), занимает больше места в индексах.
3. **Натуральные ключи предметной области** (номер серии, телефон клиента).
   Отвергнут: номер серии уникален только в рамках SKU, телефон клиента меняется,
   у аптеки натурального ключа нет вовсе.
4. **Префикс + номер / префикс + дата + номер.** Выбран.

## Решение
| сущность | формат | пример |
|---|---|---|
| справочники | `<PREFIX>-<номер с нулями>` | `SKU-000148`, `PH-0001`, `DC-01`, `SUP-0012`, `CUST-0001234`, `CARD-0001234`, `MFR-0001` |
| документы | `<PREFIX>-<YYYYMMDD>-<номер в дне>` | `RCPT-20261014-000731`, `PO-20261014-0042`, `MOV-20261014-000123` |
| партия | `BATCH-<YYYY>-<номер>` | `BATCH-2026-04417` |

Физически: `*_id bigint GENERATED ALWAYS AS IDENTITY` — PK для FK внутри базы;
`*_bk text NOT NULL UNIQUE` + `CHECK (*_bk ~ '<regex>')`; триггер
`BEFORE UPDATE` запрещает менять BK (I2). Наружу (схема `contract`) отдаётся
только BK.

## Цена решения
* Дата внутри BK документа — это **дата присвоения номера**, а не факт.
  Она может разойтись с `receipt_dt` (чек пробит в 23:59:59, записан после
  полуночи; аптека во Владивостоке живёт на UTC+10). Аналитика на дату из
  BK не опирается никогда — только на `receipt_dt`.
* Нумерация «в пределах дня» требует счётчика на (тип документа, дата) —
  дополнительная логика в генераторе/приложении.
* Два ключа на каждую таблицу (суррогат + BK) — лишний индекс.
